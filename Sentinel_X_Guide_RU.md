# IGBT Sentinel X — инструкция для команды

## В чём отличие
«TwinPulse Fingerprint»: многопараметрический цифровой отпечаток IGBT по сравнению с эталоном. Adaptive mode запускает дополнительный синтетический набор проверок лишь при аномальном, пограничном или нетипичном профиле. Возвращает SCREEN PASS / RETEST / REVIEW / REJECT, индекс здоровья и объяснение решения.

## Показ жюри (2 минуты)
1. Откройте `IGBT_Sentinel_Demo.html` в Chrome или Edge (интернет не нужен).
2. Выберите Healthy reference + Adaptive и нажмите Start diagnosis. Увидите SCREEN PASS, только 5 проверок и 4 модельные минуты.
3. Выберите Thermal drift (subtle) + Adaptive. Покажите, как необычная сигнатура запускает расширенные проверки и выводит REVIEW / REJECT.
4. Выберите Healthy reference + High uncertainty. Покажите RETEST: стенд не выдаёт разрешение при сомнительной точности.
5. Скачайте JSON evidence и CSV report. Покажите график fingerprint и evidence trail.

## Как работает модель
- Статичные исходные значения меняются в зависимости от выбранного сценария неисправности.
- Псевдопогрешность вычисляется детерминированно по серийному номеру и типу параметра. Повторение того же ввода даёт те же значения.
- Первые пять тестов оцениваются относительно *условных* границ. Если есть превышение, пограничное значение или сильное отличие от базовой сигнатуры, Adaptive добавляет четыре проверки.
- Health Index = условный штрафной индекс на основе числа и выраженности отклонений, а Confidence Index отражает только качество покрытия демонстрационных проверок и режим погрешности. Ни один из них не является оценкой физической надёжности или вероятности отказа.
- SCREEN PASS означает только отсутствие обнаруженных нарушений среди выполненных синтетических проверок; оно не разрешает установку модуля.

## Что говорить про техническую реализацию
Физический стенд требует оснастки под конкретный модуль, безопасной изоляции, проверенных измерительных приборов, независимого контроллера защит, согласованных испытательных процедур и калибровки. Высоковольтные и токовые проверки не реализованы. Верифицировать пороги и длительности с инженерами Wabtec.
