04 / Distinctive feature: Adaptive test selection

Standard tester: always executes the same checklist and reports PASS / FAIL.
Sentinel X: first screens high-priority electrical checks, then selects follow-up tests when evidence is abnormal, borderline or uncertain. It produces a triage recommendation with an explanation and fingerprint. No unperformed test is represented as passed.
